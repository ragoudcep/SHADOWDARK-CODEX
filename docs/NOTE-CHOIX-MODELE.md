# Note perso — choix du modèle Claude

Pas spécifique au Codex : un pense-bête que Tristan a demandé le 06/08/2026,
posé ici faute d'un meilleur endroit (préférence perso plutôt que doc
projet). Si un vrai mécanisme de mémoire cross-session est disponible côté
Cowork (commande `/remember` ou équivalent), c'est probablement un meilleur
endroit pour ça à terme — ce fichier reste une sauvegarde en attendant.

## Consigne

Penser à rappeler à Tristan, de temps en temps (pas à chaque message —
seulement quand c'est visiblement pertinent), qu'il peut changer de modèle
si la tâche en cours ne correspond pas à celui utilisé :

- **Haiku** : suffisant pour du volume/rapide/peu risqué — renommer un truc
  partout, reformuler un texte court, une recherche simple, une réponse
  factuelle courte. Inutile de payer plus cher pour ça.
- **Sonnet** (utilisé ce soir sur le Codex) : le bon défaut pour du dev
  réel — comprendre un bug, coordonner plusieurs fichiers, écrire/valider du
  code, faire un audit. C'est ce niveau qui a géré la session Shadowdark
  Codex (CSS, SVG/trigonométrie, cohérence multi-fichiers, coordination avec
  Dual) sans souci.
- **Opus** : à réserver pour les cas où Sonnet peine vraiment — un bug qui
  résiste après plusieurs tentatives, une décision d'architecture à fort
  enjeu, un raisonnement inhabituellement long/tordu. Pas la peine par
  défaut.

Si une conversation part sur Haiku mais dérive vers du debug/dev complexe,
ou inversement tourne sur Sonnet/Opus pour des tâches trivialement
répétitives, le signaler à Tristan une fois — pas de manière insistante.
